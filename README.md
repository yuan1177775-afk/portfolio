## 🎨 设计风格

采用**乙女游戏（Otome Game）**画风，核心特点：

- 🖤 **暗色深邃背景** — `#0d1117` 深蓝黑基底
- ✨ **星光粒子** — CSS 纯代码星空闪烁效果
- 🥇 **香槟金点缀** — 标题渐变、边框、发光阴影
- 🔮 **暗紫氛围光** — 区块背景渐变
- 📜 **宋体字族** — 思源宋体 + 衬线字体，优雅中式气质
- 💫 **微交互动画** — 头像光晕脉冲、卡片悬停发光、底部滑入动效

## 🧩 页面模块

| 模块 | 说明 |
|------|------|
| **导航栏** | 毛玻璃固定导航，滚动变色，移动端汉堡菜单 |
| **Hero** | 圆形头像 + 渐变标题 + CTA 按钮 + 滚动提示 |
| **关于我** | 个人信息 + 数据统计（年资/项目/客户） |
| **专业技能** | 6 张卡片：UI/UX · 前端 · 产品策略 · 视觉 · 内容 · 协作 |
| **精选作品** | 6 个项目卡片，带渐变封面 |
| **最新文章** | 4 篇博客卡片，带日期和分类标签 |
| **联系我** | 联系信息 + 社交媒体 + 留言表单 |
| **页脚** | 品牌信息 + 快速链接 |

## 🚀 快速开始

```bash
# 进入目录
cd my_web

# 启动本地服务器（Python）
python3 -m http.server 8080

# 浏览器打开
open http://localhost:8080
```

或直接用 VS Code Live Server 插件打开。

## 📱 响应式

- 桌面端（>1024px）：三列布局
- 平板端（768-1024px）：两列布局
- 手机端（<768px）：单列布局，汉堡菜单

## 🛠 技术栈

- 纯 HTML5 / CSS3 / Vanilla JavaScript
- 无框架依赖
- CSS 自定义属性（变量）主题系统
- Intersection Observer 滚动动画
- 星空背景纯 CSS `radial-gradient`
